# NLME
Non-linear mixed effects modeling (NLME, GLME, formerly and confusingly AFT)

Note: to view the HTML files, download them. They may not be viewable otherwise.

Files

rstan-vs-brms-NLME-on-amyloid-pet.Rmd - examples of how to fit an NLME model on a single outcome of amyloid PET. First, using the package `rstan` the R interface to Stan. Second, with the `brms` package for Bayesian Regression Models using Stan.

rstan-bayesian-multivariate-NLME-pib-tau-wmh.Rmd - examples of how to fit an NLME model on three outcomes of amyloid PET, tau PET, and white matter hyperintensity percentage with an MCMC model and the `Rstan` package.
